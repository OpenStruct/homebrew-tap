# Homebrew Tap — OpenStruct

Custom Homebrew formulae by [OpenStruct](https://github.com/OpenStruct).

## Install

```bash
brew tap openstruct/tap
brew install dx-tools
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| `dx-tools` | 23 developer tools in one CLI — JSON, JWT, ports, hashing, base64, UUID & more |

## Usage

```bash
dx --help
dx json format '{"a":1}'
dx port list
dx hash "hello"
dx uuid
```
