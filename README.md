# Homebrew Tap — OpenStruct

Custom Homebrew formulae by [OpenStruct](https://github.com/OpenStruct).

## Install

```bash
brew tap openstruct/tap
brew install dx-tools
brew install mac-disk-cleaner
brew install crosspresent
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| `dx-tools` | 23 developer tools in one CLI — JSON, JWT, ports, hashing, base64, UUID & more |
| `mac-disk-cleaner` | Find and safely delete what's filling your Mac's disk — caches, Xcode, node_modules, Docker |
| `crosspresent` | Turn one Markdown file into a self-contained HTML presentation |

## Usage

```bash
dx --help
dx json format '{"a":1}'
dx port list
dx hash "hello"
dx uuid
```
